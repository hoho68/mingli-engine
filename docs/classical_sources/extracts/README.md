# Review Note Naming

Use one Markdown review-note file per registered source id. Each file should
summarize reviewed passages into concise evidence candidates and refer back to a
page, chapter, heading, or review-note anchor.

Expected files for the initial corpus:

- `northeast_blind_peak.md`
- `duan_plain_mingxue_outline.md`
- `blind_school_secret.md`
- `blind_life_manual.md`
- `mingli_true_formula_teacher.md`
- `mingxue_golden_voice.md`
- `fortune_reading_hongfu_qitian.md`
- `immortal_fortune_jianghu_secret.md`
- `life_death_book_100_pages.md`

Review notes are maintainer material. Runtime report generation must not parse
these files directly.
